# Minganti Materiais para Construção — Protótipo

Site estático em HTML5, CSS3 e JavaScript, pronto para GitHub Pages.

## Executar
Abra `index.html` no navegador ou utilize a extensão Live Server no VS Code.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets/` para a raiz.
3. Vá a **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Selecione **main** e **/(root)**; salve e aguarde a publicação.

## Personalizar
- `script.js`: altere `WHATSAPP` e os itens em `products`.
- `index.html`: atualize links, textos e, quando houver, endereço/Google Maps.
- `style.css`: paleta e layout.
- `assets/`: imagens fornecidas pelo cliente.

## Limites do protótipo
Os produtos são exemplos baseados no material fornecido. Não há estoque, preços ou checkout real. A lista é enviada via WhatsApp, sem persistência. Para pagamentos reais, contrate um gateway com checkout hospedado e use integração segura; **não coloque tokens secretos no JavaScript público**. A criação e verificação do Google Business Profile devem ser feitas pelo proprietário da loja. Obtenha autorização para usar imagens, marcas e informações publicamente.
